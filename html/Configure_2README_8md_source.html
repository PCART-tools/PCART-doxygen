1 # Configure Directory 配置文件目录
2 
3 ## English Description
4 
5 This directory contains input configuration files (in JSON format) for PCART.
6 
7 Each configuration file includes:
8 - `projPath`: Path to the project directory.
9 - `runCommand`: The exact command to run the project.
10 - `runFilePath`: Specific run file path if not directly in the first-level subdirectory, or set to "".
11 - `libName`: Name of the upgraded Python library used (e.g., `torch`, `tensorflow`).
12 - `currentVersion`: Version of the library currently in use.
13 - `targetVersion`: Version intended to be used for migration.
14 - `currentEnv`: Path to the conda environment of the library's current version.
15 - `targetEnv`: Path to the conda environment of the library's upgraded version.

22 该目录用于存放PCART的输入配置脚本。

31 - `currentEnv`：当前库版本的conda虚拟环境路径。
32 - `targetEnv`：目标库版本虚拟环境路径。
