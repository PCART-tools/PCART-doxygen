Detailed Description

Provide some class definitions for API objects.

Defines Parameter (single API parameter), Api (full API signature), and APIOBJ (container for converting string API definitions into Api objects). These classes are used throughout the pipeline for compatibility analysis. 定义Parameter（单个API参数）、Api（完整API签名）、APIOBJ（将字符串API定义 转换为Api对象的容器）。这些类用于整个流水线的兼容性分析。
