Detailed Description

Generate repair patches without rewriting the source AST.

Uses existing callsite spans and repair results to generate independent Successful/Unknown/Failed patches. Only Successful edits enter the copied project; original files and source bytes outside edited spans stay unchanged. 使用已有调用点范围和修复结果生成三类独立补丁，仅将Successful修复写入 项目副本，不修改原项目，保留替换范围之外的原始源码字节。
