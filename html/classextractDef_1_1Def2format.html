Detailed Description

Get prefix and relative path of a source file 获取源码文件路径前缀和相对路径

The prefix denotes the fully qualified name of a source file. For example, the prefix for lib/a/b/c.py is lib.a.b.c. the relative path denotes the relative path of a source file, e.g., lib/a/b/c.py
